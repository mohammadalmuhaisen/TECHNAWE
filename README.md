# TECHNAWE 🎓

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat&logo=python)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-lightgrey?style=flat)

TECHNAWE is a user-friendly desktop application built with Python and Tkinter, designed specifically to make university life easier for students. From navigating campus facilities to effortlessly tracking academic performance, TECHNAWE is your daily campus companion.

## 🚀 Features

*   **📈 GPA Calculator**: Instantly calculate both your semester and cumulative GPA by simply entering your grades and credit hours. No more manual math!
*   **🗺️ Lab Locations Guide**: Never get lost on campus again. This feature helps you find any lab or hall easily, providing specific details (Building, Floor, Directions) along with illustrative images for visual guidance.
*   **📦 Standalone & Portable**: All visual assets (images and icons) are securely encoded in Base64 within the script itself, meaning you only need the main Python file to run the app without worrying about missing image folders.

## 🛠️ Prerequisites

To run this application, you need to have Python installed on your machine.
*   Python 3.x
*   `Pillow` library (for image handling)
